# Document Chat (RAG)

Upload PDFs, text or Markdown files and ask questions about them. Answers are generated by Gemini (free tier) and cite the excerpts they came from. Claude is supported as an optional alternative.

**Stack:** FastAPI · ChromaDB (local vector store) · all-MiniLM-L6-v2 embeddings (local, free) · Gemini API for generation · plain HTML/JS frontend.

## Setup

```bash
cd rag-app
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env             # then put your GEMINI_API_KEY in .env
uvicorn app.main:app --reload
```

Get a free Gemini key at https://aistudio.google.com/apikey (sign in with a Google account, click **Create API key**). The free tier has rate limits, so if you see a rate-limit error, wait a minute and retry.

To use Claude instead: `pip install anthropic`, then set `LLM_PROVIDER=claude` and `ANTHROPIC_API_KEY` in `.env`.

Open http://127.0.0.1:8000, drop in a document, and ask a question.

The first upload downloads the embedding model (~80 MB) and may take a minute.

## How it works

```
Upload  ->  loaders.py   extract text per page (pypdf for PDFs)
        ->  chunking.py  ~1000-char chunks with 150-char overlap
        ->  store.py     embed locally and save in ChromaDB (./data/chroma)

Ask     ->  store.query  embed the question, fetch top-5 similar chunks
        ->  rag.py       send chunks + question + recent history to Gemini (or Claude)
        ->  main.py      stream sources first, then answer tokens, to the UI
```

| File | Job |
| --- | --- |
| `app/config.py` | Settings (env vars): model, chunk size, top-k |
| `app/loaders.py` | PDF/TXT/MD text extraction |
| `app/chunking.py` | Paragraph-aware chunk splitter with overlap |
| `app/store.py` | ChromaDB wrapper: add, delete, list, similarity search |
| `app/ingest.py` | Ties loading, chunking and storing together |
| `app/rag.py` | Prompt building and LLM streaming (Gemini or Claude) |
| `app/main.py` | FastAPI routes: `/api/upload`, `/api/documents`, `/api/chat` |
| `static/index.html` | Chat UI |

## Tuning

Set these in `.env`:

- `CHUNK_SIZE` / `CHUNK_OVERLAP`: smaller chunks give more precise retrieval, larger ones give more context per hit.
- `TOP_K`: how many chunks go to the LLM per question.
- `GEMINI_MODEL`: defaults to `gemini-3.8-flash`. If it's unavailable on your free tier, pick another model from https://ai.google.dev/gemini-api/docs/models.
- `LLM_PROVIDER`: `gemini` (default) or `claude`.

Re-upload documents after changing chunk settings.

## Known limits

- Scanned/image-only PDFs have no extractable text and are rejected (they need OCR first).
- Follow-up questions like "what about the second one?" are searched as written, so retrieval can miss. Fix: rewrite the question using chat history before retrieval.
- No authentication: everyone who can reach the server shares the same documents.
